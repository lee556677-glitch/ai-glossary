AI 代理

AI Agent

進階應用 ★★★難度 3 / 3

1一句話說明

不只回答問題，還會自己規劃步驟、使用工具，一步步把任務做完的 AI。

2生活比喻

一般的聊天 AI 像打電話問路：它告訴你怎麼走，但路還是要你自己走。

AI Agent 比較像一位幫你跑腿的助理：你交代「幫我買到某本書」，他會自己查哪裡有賣、比價，下單前再跟你確認。遇到需要你本人處理的事（像是登入、付款），他會停下來問你。

3實際例子

例如你對 Agent 說「幫我把這個網站上傳到 GitHub，並開啟網頁」，它可能會這樣做：

  1. 規劃步驟：建立儲存庫 → 上傳檔案 → 開啟 GitHub Pages → 檢查網址。
  2. 打開瀏覽器，請你先自己登入 GitHub。
  3. 建立儲存庫並上傳檔案。
  4. 到設定頁開啟 GitHub Pages。
  5. 打開網址確認網頁正常，再回報結果給你。

4常見誤會

  • AI Agent 什麼都可以自己決定。

    好的 Agent 遇到付款、刪除檔案、寄信這類重要或無法復原的動作，應該先停下來問人。

  • Agent 是另一種更聰明的 AI 模型。

    Agent 背後通常還是 LLM，差別在外面加上了「工具」（瀏覽器、程式、檔案）和「一直做到完成」的流程。

5小測驗

AI Agent 和一般聊天 AI 最大的差別是什麼？

  1. Agent 講話比較有禮貌
  2. Agent 能使用工具、自己規劃多個步驟去完成任務
  3. Agent 不會產生幻覺
看答案

答案：B。會用工具、能多步驟行動，才是 Agent 的關鍵；它一樣可能出錯，所以重要步驟要讓人確認。
