詞元

Token

基礎概念 ★☆☆難度 1 / 3

1一句話說明

AI 讀寫文字的最小單位叫做 token（詞元）；模型不是一個字一個字看，而是一塊一塊地看。

2生活比喻

想像樂高積木。一句話送進 AI 之前，會先被拆成一塊塊積木：常見的詞可能一整塊，少見的詞會被拆成好幾小塊。

模型讀進來的是積木，吐出來的也是積木，最後才拼回我們看得懂的文字。負責「拆積木」的工具叫做 tokenizer（分詞器），每個模型的拆法都不太一樣。

3實際例子

用一個英文單字看看 token 是怎麼被切開的（實際切法依模型而定，這裡只是示意）：

  1. 你輸入：unbelievable
  2. 分詞器把它切成 un、believ、able 三個 token。
  3. 模型以 token 為單位理解內容，並一個 token 一個 token 地產生回答。
  4. 輸出時，再把 token 拼回我們看得懂的文字。

中文常常是一兩個字就算一個 token。很多 AI 服務的 API 是用 token 數計費，對話長度的上限也是用 token 計算。

4常見誤會

  • 一個 token 就等於一個字。

    不一定。英文常常一個單字被切成好幾個 token；中文則要看模型，一個字可能是一個或多個 token。

  • token 是工程師才需要管的事。

    用 API 時是依 token 數計費；對話太長、超過模型能處理的 token 數，AI 也會開始「忘記」前面的內容。

5小測驗

同一段話丟給不同的 AI 模型，算出來的 token 數可能不一樣，為什麼？

  1. 因為每個模型「切積木」的方式（tokenizer）不同
  2. 因為每個人的網路速度不同
  3. 因為有的模型會偷偷刪掉一些字
看答案

答案：A。每個模型有自己的分詞器，切法不同，token 數自然就不同。
