AGENTS.md / CLAUDE.md

Agent Instruction File

開發工具 ★★☆難度 2 / 3

1一句話說明

放在專案資料夾裡、寫給 AI 看的說明書：這個專案在做什麼、檔案怎麼放、要遵守哪些規則。

2生活比喻

就像打工第一天拿到的「交接手冊」。新同事不用每件事都問「東西放哪？格式長怎樣？」，翻手冊就知道。

AI 每次進到專案時，都會先讀這本手冊，就不用你每次重新交代一遍。AGENTS.md 是許多 AI 寫程式工具共同支援的檔名；Claude Code 讀的是 CLAUDE.md，所以常見做法是讓 CLAUDE.md 直接引用 AGENTS.md，兩邊共用同一份規則。

3實際例子

這個網站本身就是例子！本站的 AGENTS.md 規定每個名詞頁都要有 6 個區塊、檔名用英文小寫、要登記到 data/terms.js。看看規則寫得好不好，差在哪裡：

模糊的規則

「頁面要好看一點。」「檔名取清楚一點。」

AI 每次理解的「好看」「清楚」都不一樣，做出來的頁面就會各長各的。

具體的規則

「每個名詞頁依序包含 6 個區塊：一句話說明、生活比喻、實際例子、常見誤會、小測驗、相關名詞。」「檔名用英文小寫加連字號，例如 context-window.html。」

規則具體到可以檢查，AI 每次做出來的頁面就會一模一樣。

所以只要說一句「請依照 AGENTS.md，新增名詞：微調」，AI 就能做出格式和其他頁一致的新頁面。

4常見誤會

  • AGENTS.md 寫得越長越好。

    太長反而抓不到重點。重要的是具體、可以執行、可以檢查的規則，例如「檔名用小寫英文加連字號」就比「檔名要清楚」有用。

  • 寫了 AGENTS.md，AI 就一定會照做。

    AI 會盡量遵守，但還是可能漏掉。所以本站在 AGENTS.md 裡附了「完成前自我檢查清單」，讓 AI 和人都能逐項確認。

5小測驗

下面哪一條規則最適合寫進 AGENTS.md？

  1. 「頁面要漂亮一點。」
  2. 「每個名詞頁必須依序包含 6 個區塊，且區塊的 id 不能更改。」
  3. 「請盡量做好。」
看答案

答案：B。具體、可以檢查的規則，AI 才能每次都做出一樣的結果。
